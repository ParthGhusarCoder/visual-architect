# Changelog

## 1.0.0 - 2026-09-04

- First public-ready release.
- Adds the Visual Architect Agent Skill.
- Adds semantic modeling, automatic diagram selection, visual validation, revision diffs, and code-to-diagram consistency guidance.
- Adds the Review Canvas: a dependency-free HTML/SVG review shell with node selection, zoom, comments, and feedback JSON export.
- Adds npm CLI commands: `init`, `doctor`, `validate`, `demo`, and `path`.
