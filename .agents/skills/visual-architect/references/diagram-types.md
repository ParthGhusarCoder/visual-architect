# Diagram Type Guide

Choose by the question the reader needs answered.

| Question | Preferred diagram |
|---|---|
| What components exist and how do they connect? | Architecture |
| What happens next and where are decisions made? | Flowchart |
| Who calls whom, and in what order? | Sequence |
| What business entities exist and relate? | ER / Data Model |
| What tables, columns, PKs and FKs exist? | Database Schema |
| Where does software run? | Deployment |
| How does data move or transform? | Data Flow |
| Which role owns each process step? | Swimlane |
| What states can something enter? | State Machine |
| What depends on what? | Dependency Graph |
| What does a user experience over stages? | User Journey |
| What happens over calendar time? | Timeline / Gantt |
| What belongs under what? | Tree / Nested hierarchy |
| What abstractions sit above/below others? | Layer Stack |

## Selection rule

Choose based on semantics first, aesthetics second. If the request combines multiple questions, prefer an overview plus one or more focused diagrams rather than mixing incompatible grammars.
